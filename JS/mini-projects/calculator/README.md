# Calculator

macOS-style calculator with keyboard support.

## 🚀 Live Demo

👉 [https://courses-and-practice2.vercel.app/](https://courses-and-practice2.vercel.app/)

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Basic arithmetic operations (+, -, ×, ÷)
- Percentage and sign toggle
- Keyboard support (numbers, operators, Enter, Esc)
- Responsive layout
- Accessibility (ARIA labels)

## Usage

Clone repository and open `index.html` in browser.
